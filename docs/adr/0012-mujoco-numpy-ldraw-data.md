# ADR-0012: MuJoCo + NumPy, and how LDraw data is used

- **Status:** accepted
- **Date:** 2026-10-07

## Context
Spec 0002 needs a physics engine (ADR-0003) and LEGO part geometry. The LDraw library is ~146 MB
(CC BY 2.0 / 4.0) and must not live in the public repo.

## Decision
- Runtime deps: **mujoco** (Apache-2.0) and **numpy** (BSD) for `sim` and `construct`; `core` stays numpy-free.
- The full LDraw library is downloaded on demand (`raceforge parts fetch`) into `~/.cache/raceforge/ldraw`.
- The curated catalogue stores **precomputed per-part bounding boxes** (generated by
  `raceforge parts build-catalogue` from the library) plus hand-entered masses and connectors, so the
  quick-start, derive and MJCF steps need no LDraw download. Only rendering and `.mpd` viewing need the library.
- Catalogue data carries LDraw attribution (NOTICE).

## Consequences
Tests run without the 146 MB download. Re-generating bounding boxes needs the library once.
